POST /api/proxy

Canonicalizes, validates (SSRF check), probes upstream headers, and generates a deterministic identifier.

Request Body

{
  "url": "https://example.com/archive.zip"
}

Response (200 OK)

{
  "id": "1xK9qZa",
  "proxy_url": "http://localhost:8080/p/1xK9qZa",
  "filename": "archive.zip",
  "content_type": "application/zip",
  "size": 10485760
}

cURL Example

curl -X POST http://localhost:8080/api/proxy \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/archive.zip"}'
GET /p/{id}

Streams the file with zero-allocation buffers. Supports HTTP Range requests and caching headers.

Headers Forwarded

  • Range: bytes=0-1024 (sent by client for seeking or resume)
  • Content-Disposition: inline; filename="..."
  • Accept-Ranges: bytes

cURL Example

# Full download
curl -O -J http://localhost:8080/p/1xK9qZa

# Range request (e.g. video seeking)
curl -r 0-1023 http://localhost:8080/p/1xK9qZa -o chunk.part
